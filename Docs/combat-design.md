# 九关随机闯关平衡

当前规则、技能组合与保底数值以 README 为准。本版将固定五关改为九关种子生成，第三、六、第九关为 Boss。

## 实现约束

- 敌人随机数与奖励随机数独立；新一轮抽新种子，当前一轮敌人预先生成，不根据所选升级暗中增强。
- 血量、冲撞强度、移速、类型和技能随机；血量与冲撞强度共用预算，限制同时抽到极端强值。
- 普通遭遇一个技能，Boss 两个技能；排除吸血与护盾组合，敌人不享受玩家的联动增幅。
- 所有生成敌人的满蓄末端加打断伤害低于 80，初始元气弹不超过 27，大招蓄力至少 0.9 秒。这些限制不限制反弹后的指数伤害。
- 近战联动、超级充能联动、反弹续航联动带来明确强度跃迁。普通遭遇有概率低血量，让优秀构筑快速取胜。
- 第一个 Boss 仅有两次升级机会，奖励提供输出或半套流派的补齐选项；用户可以放弃保底选项，保留选择代价。
- 连败援助跨轮保留到完整通关，当前只在内存中保存。保底并不证明所有操作或构筑都能通关。

## 参考与适用边界

参考的是可验证的设计做法，不是照抄其他游戏的 Boss 生命数值：

- [《死亡细胞》Foundry 官方更新说明](https://deadcells.com/patchnotes/5)把基础伤害成长与变异流派分开，并描述近战、技能、生存的专精取舍。本项目借鉴为必得冲撞成长 + 随机三选一功能升级，避免纯靠抽到攻击卡才能过关。
- [《Hades》Long Winter 官方更新说明](https://www.supergiantgames.com/blog/hades-long-winter-update-patch-notes/)同时调整祝福、武器强化、Boss 攻击时序、投射物追踪和命中框。本项目借鉴的是输出组合与可读攻击节奏一起调，而非只增加生命。这些是历史设计说明，不代表两款游戏当前版本数值。

Boss 基础血量 600 / 1,000 / 1,600 是当前原型的初始平衡值。自动检查覆盖规则、安全和可达获胜路径，不能替代真实玩家的胜率、受击原因和时长数据。下一轮试玩重点记录：最终关耗时、普通冲撞与元气弹伤害占比、早撞球/末端反弹比例，以及不同升级组合的成功率，再调整生命、节奏或升级收益。

## 本轮验证

100 个种子共 900 个遭遇：检查固定 Boss 节点、相同种子可复现、不同种子存在差异、敌人技能预算、最大单次冲撞伤害、援助削弱、每轮八次三选一奖励完整性、输出保底和联动保底。另回归反弹大整数、九关流程和触屏检查。

自动检查证明规则和数值边界，不代表真人胜率。待试玩记录：三场 Boss 的失败分布、流派使用率、普通关平均击杀时间，以及援助开启前后通关率。

本轮生成与奖励检查通过 7,872 条断言，另通过 33 项技能、101 项关卡流程、15 项基础战斗、12 项合成触屏检查。由于 Mac 锁屏，本轮未进行窗口内人工试玩；上一版的实机键盘验证不代表本轮随机平衡已完成真人测试。
