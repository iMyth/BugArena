# 第一版五关肉鸽与 Boss 平衡

目标：每场都在距离、蓄力、末端命中和反弹之间做决定；成功操作有回血、强命中、翻倍爆发等奖励。升级形成组合，但不要求抽到特定升级才能击败最终 Boss。

## 当前数值

- 对手生命：80 / 140 / 220 / 350 / 1,000。
- 普通关 75 秒，Boss 150 秒。Boss 必须被击败，超时不能凭生命比例获胜。
- 玩家初始 100 生命；Iron Shell 提升至 135。每关回满，失败清空本轮升级。
- 必得成长：每次过关增加初始冲撞伤害的 25%，最终关为初始的 2 倍。与 Thunder Horn 的末端增伤乘算。
- 最终关普通末端约 46–68 伤害，Thunder Horn 后约 64–95；不含打断蓄力的额外伤害。这是近战构筑的输出路线，并非实测击杀时间。
- 元气弹基础 24（Unstable Core 为 32），每次反弹严格翻倍。24 的球累计六次反弹后为 1,536，足以击败满血 Boss。双方轮流反弹时，玩家通常需要成功顶回三次。
- Boss 半血后大招蓄力 0.95 秒、冷却 7 秒、移速 4.2；强化过渡暴露 0.9 秒破绽，大招发射后暴露 0.55 秒恢复。没有阶段锁血、回血、额外免伤或对元气弹的特殊豁免。

## 构筑与爽点

- 充能爆发：Quick Core + Unstable Core；发射更快，但强球被顶回来同样危险。
- 反弹续航：Precision Horn + Second Wind + Feedback Loop；以精准反弹换回血和冷却返还。
- 近战压制：Thunder Horn + Hunter Instinct + Fleet Feet；找距离，末端命中同时带来伤害和恢复。
- 容错：Iron Shell + Carapace Ward；护盾只挡冲撞，绝不改变元气弹非末端接触必受伤的规则。
- 每次返回有爆发粒子、音效和伤害提示；累计返回增强球体脉冲、环绕圈与拖尾。致命状态用红色环绕、白色核心和 LETHAL 提示。特效限幅独立于伤害，不扩大碰撞半径。

## 参考与适用边界

参考的是可验证的设计做法，不是照抄其他游戏的 Boss 生命数值：

- [《死亡细胞》Foundry 官方更新说明](https://deadcells.com/patchnotes/5)把基础伤害成长与变异流派分开，并描述近战、技能、生存的专精取舍。本项目借鉴为必得冲撞成长 + 随机三选一功能升级，避免纯靠抽到攻击卡才能过关。
- [《Hades》Long Winter 官方更新说明](https://www.supergiantgames.com/blog/hades-long-winter-update-patch-notes/)同时调整祝福、武器强化、Boss 攻击时序、投射物追踪和命中框。本项目借鉴的是输出组合与可读攻击节奏一起调，而非只增加生命。这些是历史设计说明，不代表两款游戏当前版本数值。

1,000 是当前原型的初始平衡值。自动检查覆盖规则、安全和可达获胜路径，不能替代真实玩家的胜率、受击原因和时长数据。下一轮试玩重点记录：最终关耗时、普通冲撞与元气弹伤害占比、早撞球/末端反弹比例，以及不同升级组合的成功率，再调整生命、节奏或升级收益。

## 本轮验证

- 15 项基础战斗、33 项超级充能/末端反弹/大整数/Boss 检查。
- 59 项关卡、升级继承、伤害成长、解锁与 Boss 限时规则检查。
- 12 项合成触屏检查，覆盖移动、冲撞、大招释放及焦点丢失清理。
- 46 项动画检查和 51 项美术检查；实际视觉代码生成反弹 0 / 1 / 3 / 8 次预览。
- 主工程 Play Mode 用真实键盘 R 重开、Q 蓄力释放，已观察到元气弹、24 伤害提示与 10 秒冷却开始。触屏布局截图已更新。
- 手机真机性能、真人 Boss 胜率和不同构筑通关时长尚未测量。
